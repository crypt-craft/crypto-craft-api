# Frontend Client Guides

Практичні приклади інтеграції фронтенду (React) з CryptoCraft API.

- auth-flow.md — авторизація гаманцем (Solana, Phantom)
- react-setup.md — налаштування клієнта (Apollo, fetch)
- token-flow.md — створення токену (unsigned → sign → submit → save)
- airdrop-flow.md — claim airdrop (unsigned → sign → submit)
- troubleshooting.md — типові помилки (NetworkError, CORS) та їх рішення
