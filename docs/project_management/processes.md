# Processes

## Agile/Scrum
- 2-тижневі спринти
- Щоденні стендапи (асинхронно у лог-файлі сесії)
- Sprint Planning: відбір з беклогу у спринт
- Sprint Review/Demo: демо ключових інкрементів
- Retrospective: 3 поліпшення на спринт

## Definition of Ready (DoR)
- Визначений користувацький сценарій і цінність
- Прийнятні критерії (AC)
- Відомі залежності і ризики

## Definition of Done (DoD)
- Код покрито тестами, збірка зелена
- Документація оновлена (`docs/`), лінтер без помилок
- Observability: логування й метрики додані
